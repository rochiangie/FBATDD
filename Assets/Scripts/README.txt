Paso a paso
1. Descargar las versiones desktop de Git y Unity
2. Clonar el proyecto y abrirlo en Github desktop
3. Abrir Unity Hub y seleccionar el proyecto
4. Instalar modulos necesarios (en installs)
5. Doble click en el proyecto para abrir Unity IDE
6. Crear branch individual
7. Empezar a editar el proyecto
8. Subir cambios con "commmit" y luego "push" (esto crea un PR que se tiene que aprovar para mergear)
